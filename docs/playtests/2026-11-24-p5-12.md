What this showed:

- **The Sótanos is not too easy where it counts.** P1-15's 95% is a week-1 number; over fresh 8-week campaigns
  Aprendiz clears 89.9%, inside 85–90. Tier-start parties (extra ranks, gear and colones) clear 92–96%, so those
  runs overstate a real campaign; the 24-week campaigns stay the measure for Veterano and Campeón, as in P5-11.
- **Veterano had become too hard (62.5%, was 77% in P5-11).** Since P5-11 the Taller sells only a weekly draw
  of weapons and armor (P3-05e), so parties reach Veterano with less gear. Veterano enemies ×1.1 / ×1.06 put it
  back at 74.9%, mid-band, with deaths 0.17 and 34 of 36 campaigns solvent.
- **Campeón is noisy at this sample size.** Its data is unchanged in all three runs: 67.9%, 49.0%, 67.8% on
  49–59 expeditions each; pooled 100 of 161 = 62%, inside 55–70. A Campeón-only retune needs more expeditions
  (start-at-tier campaigns or 24+ seeds), not a data change now.
- **Aprendiz inside long campaigns (64–69%)** is low but was never the Aprendiz band's measurement; raising
  Aprendiz difficulty would push it lower still.

`agg.py`:

```python
import re,sys,glob,os,math
# agg.py <out/setting> [mode]: per-tier clear rate, deaths, bank, money, from playtest_campaign summaries.
def wilson(k,n,z=1.96):
    if n==0: return (0,0)
    p=k/n; d=1+z*z/n; c=p+z*z/(2*n); r=z*math.sqrt(p*(1-p)/n+z*z/(4*n*n))
    return (100*(c-r)/d,100*(c+r)/d)
for d in sys.argv[1:]:
    for mode in sorted({os.path.basename(f).split('_s')[0] for f in glob.glob(d+'/*.md')}):
        tiers={}; banks=[]; camps=0; lin=[]; lout=[]; files=0; done=0
        for f in sorted(glob.glob(f"{d}/{mode}_s*.md")):
            t=open(f).read(); files+=1
            if 'Done in' in t: done+=1
            for m in re.finditer(r'^\| (aprendiz|veterano|campeon) \| (\d+) \| (\d+)% \| ([\d.]+) \|',t,re.M):
                n=int(m.group(2)); c=round(n*int(m.group(3))/100); de=float(m.group(4))*n
                a=tiers.setdefault(m.group(1),[0,0,0.0]); a[0]+=n; a[1]+=c; a[2]+=de
            mb=re.search(r'Colones in the bank: (.*)',t)
            if mb:
                for cm in mb.group(1).split(';'):
                    v=re.findall(r'wk \d+: (-?\d+)',cm)
                    if v: banks.append(int(v[-1])); camps+=1
            m1=re.search(r'^\| Loot \(fights, curios, objective\) \| (\d+)',t,re.M); m2=re.search(r'^\| \*\*All hub spending\*\* \| (\d+)',t,re.M)
            if m1 and m2: lin.append(int(m1.group(1))); lout.append(int(m2.group(1)))
        print(f"## {d} [{mode}] runs {done}/{files}")
        tot=[0,0,0.0]
        for tier in ('aprendiz','veterano','campeon'):
            if tier in tiers:
                n,c,de=tiers[tier]; lo,hi=wilson(c,n); tot=[tot[0]+n,tot[1]+c,tot[2]+de]
                print(f"  {tier:9s} {100*c/n:5.1f}% ({c}/{n}, CI {lo:.0f}-{hi:.0f})  deaths/exp {de/n:.2f}")
        if tot[0]: print(f"  overall   {100*tot[1]/tot[0]:5.1f}% ({tot[1]}/{tot[0]})  deaths/exp {tot[2]/tot[0]:.2f}")
        if banks: print(f"  bank >=500 at end: {sum(b>=500 for b in banks)} of {len(banks)}  median {sorted(banks)[len(banks)//2]}")
        if lin: print(f"  money in/out per week: {sum(lin)//len(lin)} / {sum(lout)//len(lout)}")
```
