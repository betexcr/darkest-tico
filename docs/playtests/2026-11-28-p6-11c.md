# P6-11c — Cañaverales Profanados against the Sótanos

Same method as P6-10c: the Sótanos are tuned to the owner's per-tier bands with long campaigns; a new region is
measured with the same bot runs as the Sótanos and should sit within about ±5 points on each tier.

## El Capataz de Ceniza (boss sim, 2000 fights, party at the region's level 1/4/6, ranks 2/3/4, gear above Aprendiz)

## Bot campaigns (cleared % of 96 expeditions; all failures were Retiradas unless noted)

| Run | Sótanos | Cañaverales P6-11a | Round 2 (Capataz + elites) | **Kept** (+ gentler fire hazard, Humo 6) |
|---|---:|---:|---:|---:|
| Aprendiz, arrival party (level 1, ranks 2) | 95.8% | 92.7% | 92.7% | **84.4%** |
| Veterano tier-start | 100% | 81.3% | 87.5% | **96.9%** |
| Campeón tier-start | 71.9% | 77.1% (2 deaths) | 79.2% | **78.1%** |
| Aprendiz, fresh level 0 | 87.5% | 19.8% | 56.3% | **65.6%** |

Per seed (kept): arrival 92 / 83 / 75 / 88; Veterano 88 / 100 / 100 / 100; Campeón 92 / 75 / 54 / 92; fresh
42 / 67 / 67 / 88. No script errors in any run; no deaths in the kept runs.

What this showed:

- **The Capataz's long fights were the problem**, not his win rate: on Veterano the bot fled 12–20-round boss
  fights it reached already stressed. Fewer Quemadores and a slower burn cut the fight to ~8 rounds; the region's
  fire hazard (now 5% of moves, 1 stress) was the rest of the Veterano gap (81% → 97%).
- **Seed-to-seed swings are large** (54–92% on Campeón, 75–92% on arrival); 96 expeditions give roughly ±8 points.
  The arrival party cleared 92.7% in two earlier rounds and 84.4% in the last with the Aprendiz-relevant data barely
  changed (only the fire hazard got easier), so the true value is about 88% (192 expeditions pooled), a little under
  the Sótanos and inside the owner's 85–90 band.
- **Campeón is a bit easier than the Sótanos** (78% vs 72%), like the Bosque (74%). The owner's playtest decides
  whether the Capataz's Campeón variant needs more teeth.
- **Fresh level-0 parties still struggle** (66%), but the Cañaverales open only after the Mayordomo.
